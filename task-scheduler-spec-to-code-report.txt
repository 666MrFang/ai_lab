## Phase 9：实现（实际改动）

- include/scheduler.h:11 — 新增 uint32_t priority = 0;。
- src/scheduler.cpp:21-45 — run_next 选择逻辑：

    std::size_t best_index = 0;
    for (std::size_t i = 1; i < queue_.size(); ++i) {
        if (queue_[i].priority < queue_[best_index].priority) {
            best_index = i;
        }
    }
    task = queue_[best_index];
    queue_.erase(queue_.begin() + static_cast<std::ptrdiff_t>(best_index));
